Regula Falsi Method

Root-finding algorithm using linear interpolation (False Position Method)

description

Mathematical Discussion

The Regula Falsi (False Position Method) is a bracketing numerical algorithm used to find the roots of a continuous, nonlinear equation \(f(x) = 0\). It improves upon the Bisection method by using proportional linear interpolation between two points rather than a simple midpoint.

Formula

\[ c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} \]

Error Formula

\[ \varepsilon_a = \left| \frac{c_{\text{new}} - c_{\text{old}}}{c_{\text{new}}} \right| \times 100\% \]

Convergence

The Regula Falsi method exhibits linear convergence, which is faster than the bisection method but slower than Newton-Raphson. The method is guaranteed to converge when a sign change exists in the initial interval.
