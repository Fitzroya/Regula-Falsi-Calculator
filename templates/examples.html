Example 1: f(x) = x² - 4

Interval: [1, 3] Tolerance: 5% True Root: x = 2

Step-by-Step Solution:

Step 1: Check if interval brackets a root

\(f(a) = f(1) = (1)^2 - 4 = 1 - 4 = -3\)

\(f(b) = f(3) = (3)^2 - 4 = 9 - 4 = 5\)

Since \(f(1) \cdot f(3) = (-3)(5) = -15 < 0\), a root exists in \([1, 3]\).

Iteration 1:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{1 \cdot 5 - 3 \cdot (-3)}{5 - (-3)} = \frac{5 + 9}{8} = \frac{14}{8} = 1.6\)

\(f(c) = (1.6)^2 - 4 = 2.56 - 4 = -1.44\)

Check sign: \(f(a) \cdot f(c) = (-3)(-1.44) = 4.32 > 0\) → root is between \(c\) and \(b\)

Update: \(a = c = 1.6\), \(b = 3\)

Iteration 2:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{1.6 \cdot 5 - 3 \cdot (-1.44)}{5 - (-1.44)} = \frac{8 + 4.32}{6.44} = \frac{12.32}{6.44} = 1.857\)

\(f(c) = (1.857)^2 - 4 = 3.448 - 4 = -0.551\)

Relative Error: \(\varepsilon_a = \left|\frac{1.857 - 1.6}{1.857}\right| \times 100\% = 13.84\%\)

Update: \(a = 1.857\), \(b = 3\)

Iteration 3:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{1.857 \cdot 5 - 3 \cdot (-0.551)}{5 - (-0.551)} = \frac{9.285 + 1.653}{5.551} = \frac{10.938}{5.551} = 1.952\)

\(f(c) = (1.952)^2 - 4 = 3.810 - 4 = -0.189\)

Relative Error: \(\varepsilon_a = \left|\frac{1.952 - 1.857}{1.952}\right| \times 100\% = 4.87\%\)

\(\varepsilon_a = 4.87\% < 5\%\) → Converged

Example 2: f(x) = cos(x) - x

Interval: [0, 1] Tolerance: 0.1% True Root: x ≈ 0.739085

Step-by-Step Solution:

Step 1: Check if interval brackets a root

\(f(a) = f(0) = \cos(0) - 0 = 1 - 0 = 1\)

\(f(b) = f(1) = \cos(1) - 1 = 0.5403 - 1 = -0.4597\)

Since \(f(0) \cdot f(1) = (1)(-0.4597) = -0.4597 < 0\), a root exists in \([0, 1]\).

Iteration 1:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{0 \cdot (-0.4597) - 1 \cdot (1)}{-0.4597 - 1} = \frac{0 - 1}{-1.4597} = \frac{-1}{-1.4597} = 0.684\)

\(f(c) = \cos(0.684) - 0.684 = 0.774 - 0.684 = 0.090\)

Check sign: \(f(a) \cdot f(c) = (1)(0.090) = 0.090 > 0\) → root is between \(c\) and \(b\)

Update: \(a = c = 0.684\), \(b = 1\)

Iteration 2:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{0.684 \cdot (-0.4597) - 1 \cdot (0.090)}{-0.4597 - 0.090} = \frac{-0.314 - 0.090}{-0.5497} = \frac{-0.404}{-0.5497} = 0.735\)

\(f(c) = \cos(0.735) - 0.735 = 0.745 - 0.735 = 0.010\)

Relative Error: \(\varepsilon_a = \left|\frac{0.735 - 0.684}{0.735}\right| \times 100\% = 6.94\%\)

Update: \(a = 0.735\), \(b = 1\)

Iteration 3:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{0.735 \cdot (-0.4597) - 1 \cdot (0.010)}{-0.4597 - 0.010} = \frac{-0.338 - 0.010}{-0.4697} = \frac{-0.348}{-0.4697} = 0.741\)

\(f(c) = \cos(0.741) - 0.741 = 0.739 - 0.741 = -0.002\)

Relative Error: \(\varepsilon_a = \left|\frac{0.741 - 0.735}{0.741}\right| \times 100\% = 0.81\%\)

Since \(f(c) < 0\) and \(f(b) < 0\), update: \(b = 0.741\), \(a = 0.735\)

Iteration 4:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{0.735 \cdot (-0.002) - 0.741 \cdot (0.010)}{-0.002 - 0.010} = \frac{-0.00147 - 0.00741}{-0.012} = \frac{-0.00888}{-0.012} = 0.740\)

\(f(c) = \cos(0.740) - 0.740 = 0.739 - 0.740 = -0.001\)

Relative Error: \(\varepsilon_a = \left|\frac{0.740 - 0.741}{0.740}\right| \times 100\% = 0.14\%\)

Update: \(b = 0.740\), \(a = 0.735\)

Iteration 5:

\(c = \frac{a \cdot f(b) - b \cdot f(a)}{f(b) - f(a)} = \frac{0.735 \cdot (-0.001) - 0.740 \cdot (0.010)}{-0.001 - 0.010} = \frac{-0.000735 - 0.0074}{-0.011} = \frac{-0.008135}{-0.011} = 0.7396\)

\(f(c) = \cos(0.7396) - 0.7396 = 0.7395 - 0.7396 = -0.0001\)

Relative Error: \(\varepsilon_a = \left|\frac{0.7396 - 0.740}{0.7396}\right| \times 100\% = 0.054\%\)

\(\varepsilon_a = 0.054\% < 0.1\%\) → Converged!
